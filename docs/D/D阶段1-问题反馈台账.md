## 1. 使用与更新规则

1. D 发现问题后先登记本台账，再通过小组沟通渠道通知责任人；
2. 每个问题必须保留版本、复现步骤、实际结果、预期结果和证据路径；
3. 修复后，D 记录修复 Commit，先复跑原问题，再执行关联回归；
4. 未收到 B 冻结产物前，任何代码问题均只能标记为“待处理”，不得自行关闭；
5. 不在台账中记录数据库密码、`.env` 内容、Cookie、会话 ID 或其他敏感信息；
6. 状态只可为：`新建`、`已反馈`、`处理中`、`待复测`、`已关闭`、`延期接受`。
