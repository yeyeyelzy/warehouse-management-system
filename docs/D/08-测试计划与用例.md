# 08-测试计划与用例

> 负责人：成员 D（测试、前端联调与演示）<br>
> 测试基线：`main` / `f567731dc08f1869692cb9119dd417446c712f71`<br>
> 适用范围：FR-01 至 FR-06 的最终集成版本

## 1. 目标与范围

本计划验证登录与角色权限、采购入库、FIFO/LIFO 出库、库存盘点、仓库调拨、库存查询/预警/报表的页面—后端—数据库闭环。测试结论必须同时关联版本、操作结果和数据库核对结果；不以单纯 HTTP 200 作为通过依据。

### 1.1 页面流程与入口

| 业务 | 页面/接口入口 | 主要操作与可见结果 |
| --- | --- | --- |
| 登录与权限 | `/login`、`/home`、`/logout` | 登录、未登录跳转、角色菜单控制、越权拒绝、退出失效 |
| 采购入库 | `/biz/inbound` | 仓库、货品、数量、单价、供应商；成功提示与库存联动 |
| 销售/领料/退货出库 | `/biz/outbound`、`/biz/materialIssue`、`/biz/return` | FIFO/LIFO 成本提示、库存不足回滚、领料/采购退货成本展示 |
| 盘点与调拨 | `/biz/stocktake`、`/biz/transfer` | 盘盈/盘亏、负实盘拒绝、两仓原子调拨 |
| 查询展示 | `/stock`、`/warning`、`/report` | 库存、预警和统计数据与数据库一致 |

## 2. 环境、数据与执行规则

1. 仅在本机隔离实验库执行；数据库连接由未提交的 `.env` 或进程环境变量提供，测试记录不得包含真实凭据。
2. 数据库从 `code/sql` 按顺序执行：`01_create_tables.sql`、`02_create_views.sql`、`03_create_triggers.sql`、`04_create_procedures.sql`、`05_test_and_verify.sql`、`08-rbac-lab.sql`；回归与一致性核对继续执行 `06_regression.sql`、`07-数据一致性验证.sql`。
3. 应用从 `code/src` 启动。每轮开始记录分支与 Commit；代码或 SQL 变更后必须重跑受影响用例。
4. 写库测试同时保留页面/HTTP 结果与数据库结果；失败场景需核对库存、批次、单据数在前后保持一致。

## 3. 测试用例

| 编号 | 类别 | 场景与操作 | 预期结果 |
| --- | --- | --- | --- |
| AUTH-01 | 权限 | 未登录访问 `/home`、`/biz/inbound`，并 POST 盘点 | 跳转登录页，不读取或写入业务数据 |
| AUTH-02 | 权限 | 采购角色访问盘点；领料角色访问入库；仓管访问系统管理 | 页面与直接请求均返回拒绝 |
| AUTH-03 | 权限 | 管理员访问用户/角色管理，退出后访问受限页面 | 管理员可访问；退出后会话失效 |
| AUTH-04 | 安全 | 正确/错误密码登录，新增/改密用户 | 正确凭据可登录；错误拒绝；数据库不存明文密码 |
| IN-01 | 功能 | 提交合法采购入库 | 成功提示；入库单、库存和批次同步增加 |
| IN-ERR-01 | 边界 | 入库数量为 0、单价为负、仓库/货品为空 | 明确提示；不产生写入 |
| OUT-FIFO-01 | 功能 | FIFO 货品两批入库后出库 120 | 成本 620.00，剩余 30×6.00 |
| OUT-LIFO-01 | 功能 | LIFO 货品两批入库后出库 120 | 成本 650.00，剩余 30×5.00 |
| OUT-ERR-01 | 异常 | 数量为 0、超可用库存、仓库/货品无效 | 明确提示；库存、批次、单据均无部分写入 |
| ISSUE-01 | 功能 | 提交领料出库 | 成功提示包含本次出库成本 |
| RETURN-01 | 功能 | 提交采购退货出库 | 成功提示包含本次出库成本 |
| STOCKTAKE-01 | 集成 | 账实不一致盘点 | 盘盈/盘亏记录、库存修正和批次一致 |
| STOCKTAKE-ERR-01 | 异常 | 实盘数量为负 | 被拒绝，无盘点或库存修正写入 |
| TRANSFER-01 | 集成 | 合法调拨 | 源仓减少、目标仓增加、合计不变 |
| TRANSFER-ERR-01 | 异常 | 调拨量大于源仓库存 | 失败且两仓库存、批次、调拨单不变 |
| QUERY-01 | 功能 | 查看库存、预警、统计页面 | 展示数据与视图/业务记录一致 |
| DB-01 | 数据回归 | 执行 C01～C18 及 `07-数据一致性验证.sql` | 所有回归通过，最终异常检查为 0 行 |

## 4. 通过与退出标准

- Maven 构建成功，数据库可按固定顺序初始化；
- 登录、合法/越权访问、入库、FIFO/LIFO 出库、盘点、调拨、查询均有可复现结果；
- 库存不足、负盘点、调拨不足和非法参数无部分写入；
- 库存、批次、单据、预警的一致性检查无关键异常；
- S1/S2 缺陷已关闭，或由 A 书面接受风险；
- 测试报告与演示脚本使用同一冻结 Commit。
