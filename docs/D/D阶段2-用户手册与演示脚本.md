# D 阶段二：用户手册与演示脚本

> 适用版本：`main` / `f567731dc08f1869692cb9119dd417446c712f71`<br>
> 执行人：成员 D（演示与测试）

## 1. 演示前准备

1. 确认 MySQL 已启动，并仅使用实验隔离库；不要在含有他人数据的库上执行初始化脚本。
2. 在 `code/src` 同级工作目录准备本机 `.env`，其字段以项目中的 `.env.example` 为准；真实凭据不提交 Git。
3. 在 `code/sql` 按顺序执行：`01_create_tables.sql`、`02_create_views.sql`、`03_create_triggers.sql`、`04_create_procedures.sql`、`05_test_and_verify.sql`、`08-rbac-lab.sql`。需要完整回归时再执行 `06_regression.sql` 和 `07-数据一致性验证.sql`。
4. 在 `code/src` 运行 `mvn spring-boot:run`，确认服务监听 `8080` 后访问 `http://127.0.0.1:8080/login`。

## 2. 课堂演示顺序

| 步骤 | 操作 | 预期展示 |
|---|---|---|
| 1 | 未登录直接访问 `/biz/inbound` | 被重定向到登录页 |
| 2 | 用采购角色登录，打开入库页面 | 可访问采购入库；无盘点菜单/盘点接口权限 |
| 3 | 提交一笔合法采购入库 | 成功提示，库存与批次增加 |
| 4 | 将入库数量改为 `0`，再次提交 | 明确提示“入库数量必须大于0”，不产生单据 |
| 5 | 登录仓管角色，执行销售出库 | 成功提示中显示“出库成本 = …”；可说明 FIFO/LIFO 由货品计价方式决定 |
| 6 | 执行领料出库或采购退货 | 成功提示同样显示出库成本 |
| 7 | 执行盘点与调拨 | 正常操作成功；超库存调拨或负盘点被拒绝且数据不变 |
| 8 | 登录系统管理员 | 可进入用户管理、权限管理；演示新增/修改用户后密码不以明文入库 |
| 9 | 退出登录后重访受限页面 | 再次跳转登录页 |

## 3. 演示后的核对与恢复

1. 执行 `07-数据一致性验证.sql`，确认异常检查结果为 0 行。
2. 如需恢复干净数据，重新按第 1 节的 SQL 顺序构建实验库；该操作会清空该实验库业务表，执行前再次确认目标库。
3. 保存的演示证据不得包含真实数据库密码、`.env` 内容、Cookie 或会话标识。

## 4. 常见问题

| 现象 | 排查/处理 |
|---|---|
| 应用可启动但无法登录 | 检查 MySQL 服务、`.env` 中的数据库地址/库名/账号配置是否与隔离库一致；不要把实际密码写进代码或文档 |
| SQL 执行提示对象已存在 | 在确认是实验隔离库后，从 `01_create_tables.sql` 起重新构建；不要混用旧版本脚本 |
| 页面显示无权限 | 确认演示账号角色与要演示的菜单/操作匹配；这是 RBAC 的预期行为 |
| 库存不足或盘点/调拨失败 | 这是可用于演示回滚的正常业务提示；用新建测试数据重放成功路径 |
