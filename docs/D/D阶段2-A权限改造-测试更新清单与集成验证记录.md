## 4. D 的复测入口

1. 在自己的隔离 MySQL 实例依次执行 `code/sql/01_create_tables.sql` 至 `05_test_and_verify.sql`、`08-rbac-lab.sql`，需要完整数据库回归时再执行 `06_regression.sql`、`07-数据一致性验证.sql`。A 的角色、权限和演示账号由独立的第 08 脚本提供。
2. 依照 `code/src/.env.example` 在本机配置 `.env`；实际 `.env` 不提交版本库。
3. 启动 `code/src` 中的 Spring Boot 应用。
4. 运行 `docs/A/验证脚本/Verify-Auth.ps1`；管理员持久化验证仅可在隔离库运行，并显式传入 `-ConfirmLabWrites`。
5. 将命令输出、截图（如需）和测试时间填入 `D阶段2-回归测试记录.md`；若基线 SHA 变化，必须重新记录结果。
