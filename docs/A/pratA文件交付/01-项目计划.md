# 仓库管理系统 软件开发项目计划

## 1 引言

### 1.1 编写目的

本计划规定仓库管理系统课程设计项目在 2026-11-1 至 2026-11-25 交付窗口内的**范围、组织、工作分解、进度、资源、风险、质量保证与交付物**，作为团队内部执行与评审的共同基准。凡与本计划不一致的进度承诺，须经变更控制流程（见《03-配置管理计划》）登记后生效。

### 1.2 项目背景

企业仓储业务中，手工台账与电子表格方式存在数据冗余、账实不符、查询统计困难、FIFO/LIFO 成本核算不可追溯等问题。本项目以课程设计为约束条件，建设一个覆盖采购入库、销售出库、领料回料、退货、调拨、盘点全流程的 B/S 仓库管理系统，并将**入库、出库成本核算、盘点、调拨四类核心业务逻辑下沉到 MySQL 存储过程与触发器**，以体现数据库课程的设计重点。

### 1.3 术语与缩略语

| 术语 | 说明 |
| --- | --- |
| WMS | Warehouse Management System，仓库管理系统 |

## 2 项目概述

### 2.1 项目目标

1. **功能目标**：实现货品、分类、供应商、仓库主数据维护；采购入库、销售出库、领料出库、回料入库、退货、调拨、盘点、库存查询、预警、报表全流程贯通。
2. **数据库目标**：落地 19 张表（业务表 11 张 + 辅助表 8 张）、4 个视图、8 个触发器、4 个存储过程，主外键与唯一约束齐备，全部业务具备事务保护与异常回滚。
3. **权限目标**：落地 4 角色 × 13 权限编码的功能级 RBAC，实现菜单隐藏、直达 URL 拦截（GET/POST 均返回 403）、管理功能由角色 1 独占。
4. **可交付目标**：形成"源码 + SQL 脚本 + 四份工程文档 + 演示脚本 + 测试证据"的可复现交付包，在干净环境中一次启动成功。

| SQL 回归 | 脚本 01~05 + 08 顺序执行、业务算例 | C | 零报错，库存/成本/批次与算例一致 |
| 接口与权限 | 匿名、越权、合法会话、管理写操作 | D | 302 / 403 / 200 与预期逐条一致 |
| 业务走查 | 入库→出库→领料→回料→退货→盘点→调拨 | D | 每步库存与资金可手算复现 |
| 非功能抽检 | 响应时间、易用性、编码 | D | 列表页秒级返回，表单有提示 |

### 7.4 缺陷分级与处置

| 级别 | 定义 | 处置时限 |
| --- | --- | --- |
| P0 | 系统不可启动、数据错乱、越权可写 | 当日闭环，阻塞发布 |
| P1 | 主要流程失败、权限判断错误、事务未回滚 | 当日闭环，阻塞 R0 |
| P2 | 提示文案、排版、报表维度缺失 | R0 前修复或转为已知问题记录 |
| P3 | 优化建议 | 记入待办，不阻塞发布 |
