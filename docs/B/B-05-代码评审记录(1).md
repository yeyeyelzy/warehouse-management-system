## 4. C 成员事务复核意见

- 复核确认：`sp_inbound`、`sp_outbound_cost` 均以 `START TRANSACTION` + `EXIT HANDLER FOR SQLEXCEPTION` 包裹，异常时 `ROLLBACK`；
- 确认库存累加（trg_inbound_item_after_insert）、扣减（trg_outbound_order_after_approve）与存储过程同一事务，回滚时同步撤销，不存在部分写入；
- 要求 B 严格按 5.1/5.2 存储过程契约传参，变更需双向同步。

## 5. D 成员可测试性复核意见

- 确认接口参数与返回（success/error/warning 三类 flash 消息）可在页面复现；
- 确认库存不足、数量为 0、负单价三类异常均有明确提示，可写入测试用例；
- 建议提供「库存不足」的可复现前置数据（详见 C 的演示数据脚本）。

## 6. 评审结论

核心入库、出库业务代码职责边界清晰、事务由数据库保证、错误提示可读；本轮另完成密码安全加固（F-04）。F-03 移交成员 A，其余结论进入需求—设计—测试追踪矩阵（A 维护）。
