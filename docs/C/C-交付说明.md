## 2. 执行与交接约定

在可重置的隔离库中依次执行 `01`、`02`、`03`、`04`、`05`、`08`，需要回归时继续执行 `06`、`07`。默认连接契约为 `localhost:3306/warehouse_db`，使用 `WAREHOUSE_DB_USERNAME`、`WAREHOUSE_DB_PASSWORD` 注入本机凭据；真实 `.env` 不作为交付物。

入库、出库、盘点、调拨分别由 `sp_inbound`、`sp_outbound_cost`、`sp_stocktake`、`sp_transfer` 提供事务边界。B 按过程契约调用，D 按 `07-数据一致性验证.sql` 核对库存、批次、单据和预警。
