# 第二次答辩系统演示操作脚本

> 用途：现场照着演示。启动系统后按顺序操作，每步标注了对应的数据库底层对象（存储过程 / 触发器 / 视图），讲解时点明即可。

**演示前准备**
1. 已执行 `code/sql/01~05` 脚本（建表、视图、触发器、存储过程、测试数据）。
2. 已启动 Spring Boot 系统，浏览器打开 `http://localhost:8080`。

---

## 第 1 步：登录
- 操作：输入账号 `user01`、密码 `123456`，点击登录。
- 底层对象：`sys_user` 表（`SysUserMapper.findByUsername`）。
- 讲解：系统采用登录认证，校验通过进入主页。

## 第 2 步：货品查看
- 操作：点击顶部导航「货品管理」，查看货品列表（编码、名称、计价方式 FIFO/LIFO、上下限）。
- 底层对象：`goods` 表（`GoodsMapper.list`）。
- 讲解：货品表中 `cost_method` 字段决定该货品出库时采用 FIFO 还是 LIFO。

## 第 3 步：采购入库
- 操作：进入「采购入库」，选择仓库、货品，填数量 100、单价 5，提交。
- 底层对象：**存储过程 `sp_inbound`** + **触发器 `trg_inbound_item_after_insert`**。
- 讲解：入库明细插入后，触发器自动累加该仓库该货品的库存数量与占用资金，无需 Java 代码重复更新库存。

## 第 4 步：销售出库（切换 FIFO/LIFO）
- 操作：进入「销售出库」，先选一个 FIFO 货品出库 120，观察返回「出库成本 = 620」；再选一个 LIFO 货品出库 120，观察「出库成本 = 650」。
- 底层对象：**存储过程 `sp_outbound_cost`**（按 `goods.cost_method` 用游标遍历 `stock_batch`，FIFO 升序、LIFO 降序扣批次）+ **触发器 `trg_outbound_order_after_approve`**（审核通过扣减库存）。
- 讲解：出库成本由数据库存储过程核算，演示 FIFO/LIFO 两种计价方式得到不同成本。

## 第 5 步：领料出库
- 操作：进入「领料出库」，选仓库、货品、数量，提交。
- 底层对象：复用 **存储过程 `sp_outbound_cost`**（`biz_type=MATERIAL_ISSUE`）。
- 讲解：领料复用通用出库过程，仅用 `biz_type` 区分，不额外开发独立流程。

## 第 6 步：回料入库
- 操作：进入「回料入库」，选仓库、货品、数量、单价，提交。
- 底层对象：复用 **存储过程 `sp_inbound`**（`biz_type=MATERIAL_RETURN`）。
- 讲解：回料复用通用入库过程，`biz_type` 区分业务类型。

## 第 7 步：退货处理
- 操作：进入「退货处理」，分别演示「采购退货（出库）」与「销售退货（入库）」，提交。
- 底层对象：`sp_outbound_cost(PURCHASE_RETURN)` / `sp_inbound(SALE_RETURN)`，均在事务内执行。
- 讲解：退货属于异常业务，走事务处理，失败自动回滚。

## 第 8 步：库存盘点（盘盈 / 盘亏）
- 操作：进入「库存盘点」，先对某货品实盘填一个大于账面的大数（如 500）提交，看到「盘盈 GAIN」；再对另一货品实盘填 0 提交，看到「盘亏 LOSS」。
- 底层对象：**存储过程 `sp_stocktake`**（写入 `stocktake_order/stocktake_item` 并修正库存）。
- 讲解：盘点自动比对账面与实盘，生成盘盈盘亏记录并修正库存。

## 第 9 步：仓库调拨
- 操作：进入「仓库调拨」，选调出仓库、调入仓库、货品、数量，提交。
- 底层对象：**存储过程 `sp_transfer`**（源仓扣减、目标仓增加，同一事务，支持 JSON 多货品批量）。
- 讲解：跨仓库转移，源减目标增在同一事务内，任一项失败整体回滚。

## 第 10 步：查看库存与预警记录
- 操作：进入「库存查询」，看实时库存总览（数量、占用资金、状态）；再进入「库存预警查看」，看预警货品与预警记录。
- 底层对象：**视图 `v_stock_overview`**、**视图 `v_stock_warning`**、**表 `stock_alert`**（由触发器 `trg_stock_after_insert/update` 自动生成）。
- 讲解：库存低于下限/高于上限时，触发器自动写入预警记录。

## 第 11 步：打开统计报表
- 操作：进入「统计报表」，依次查看「出入库汇总」「供应商供货统计」「盘点盈亏汇总」三组结果。
- 底层对象：对应 8 条统计 SQL 中的 3 组（复用 `code/sql/02_create_views.sql` 统计语句）。
- 讲解：满足答辩「至少 3 个统计功能」的演示要求。

---

## 答辩要点速记

- **表数量**：19 张业务表（业务 11 + 辅助 8），满足「实体表不少于 9 张」。
- **范式**：全部满足第三范式。
- **触发器**：入库累加、出库审核扣减、库存预警、删除修改回滚，共 8 个触发器对象。
- **存储过程**：入库、FIFO/LIFO 出库成本核算、盘点、调拨，均含事务与异常回滚。
- **视图**：4 个视图 + 8 条统计 SQL。
- **FIFO/LIFO**：出库成本核算在数据库侧完成。
- **数据量**：基础表各 30 行，明细关联记录 204 条（≥200）。
- **创新点**：预留 DeepSeek API 自然语言转 SQL 接口（`DeepSeekController` / `DeepSeekClient`）。
